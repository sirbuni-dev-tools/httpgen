---
NAME
    httpgen environment files

DESCRIPTION
    Requests use variables such as {{HOST}} that the HTTP Client takes from environment files next to the .http files. httpgen creates them when missing and only ever adds missing keys, so values you set are kept.

FILES
    | http-client.env.json          HOST, and for GraphQL AUTH_URL, GRANT_TYPE, CLIENT_ID, USERNAME
    | http-client.private.env.json  CLIENT_SECRET and PASSWORD (GraphQL only); never commit it

    HOST is http://localhost:<server.port><server.servlet.context-path> from application.properties or application.yml, reading the default of a ${VAR:default} placeholder, else http://localhost:8080. AUTH_URL is HOST followed by /oauth2/token; change it once if your login lives elsewhere.

USING THEM
    In IntelliJ IDEA pick the environment in the Run with list at the top of the .http file. The ijhttp runner takes --env-file, --private-env-file and --env.
